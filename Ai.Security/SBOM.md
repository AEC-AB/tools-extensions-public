# Software bill of materials

One CycloneDX file per source repo, generated by the agent runner before every security review from the manifests in the checkout (OWASP cdxgen, spec 1.6). See [SBOM/README.md](SBOM/README.md) for the index and how to regenerate. [Dependencies.md](Dependencies.md) is written from these files.

Source-only: versions as declared in the manifests, no license lookup, no vulnerability data. Serial numbers and timestamps are stripped so a file changes only when a dependency changes; git history is the change log. The same generator command is meant to run in the build pipeline so a released installer ships the SBOM it was built from.
