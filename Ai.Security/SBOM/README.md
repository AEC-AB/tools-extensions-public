# Software bill of materials

One CycloneDX 1.6 file per source repo, generated by the runner (`services/aec.agents/sbom/run-sbom.sh`, OWASP cdxgen 13.0.1) from the manifests in the checkout before each security review. Source-only: versions as declared, no license lookup, no vulnerability data. The files are the authority for `Dependencies.md`; the agent reads them and never edits them. Serial numbers and timestamps are stripped so a file only changes when a dependency changes.

| Repo | File | Components | Ecosystems |
|---|---|---|---|
| tools-extensions-public | [`tools-extensions-public.cdx.json`](tools-extensions-public.cdx.json) | 10 | github 3, nuget 7 |

Regenerate by hand with `services/aec.agents/sbom/run-sbom.sh <workspace> <output-dir>`, which pins the exact cdxgen image by digest. The same command belongs in the build pipeline so a release ships the SBOM it was built from.
